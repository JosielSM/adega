# Opções de ícone — Distribuidora

1. **Essencial**: uma garrafa sólida sobre azul.
2. **Contorno**: traço azul sobre marrom.
3. **Monograma**: letra D com garrafa em espaço negativo.
4. **Seleção**: duas garrafas em azul, marrom e creme.

Cada versão inclui SVG editável e PNG de 180, 192 e 512 pixels. O PNG de 180 pixels serve para o ícone Apple; os de 192 e 512 para o manifesto PWA. Os fundos são opacos e os elementos principais ficam na área central para acomodar máscaras do sistema operacional.

`comparacao.png` mostra as quatro opções e uma prévia de cada uma em tamanho pequeno. Nenhuma opção foi aplicada ao sistema publicado.
